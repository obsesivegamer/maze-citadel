Build the maze

Every tower is also a wall

Towers block the tile they stand on, so where you build decides the demons' road. Stretch it and every tower gets longer to shoot. On the real 20 × 28 tile plateau the glowing path redraws with every tower you place.

Wall as hard as you like, but never shut the road: a tower that would cut the portal off from the gate won't build. Try it on this practice board.

Read the wave

Know what's coming, build what counters it

Three seconds before a wave spawns, its banner names what is coming: the creeps, their armor class and their element. Each element deals double damage to the next one around the ring and half to the one before it.

Install

Three steps to the citadel

On a Mac

  1. Open the disk image

    Double-click {{dmg_name}} in your Downloads folder.

  2. Drag Maze Citadel to Applications

    Or play it straight from the disk image. Nothing else to install.

  3. Double-click to play

    The game opens straight into the citadel with the builder ready.

  4. Allow it once in Privacy & Security

    Maze Citadel isn't notarized by Apple yet, so the first double-click shows "Apple could not verify Maze Citadel is free of malware". Click Done, then open System Settings → Privacy & Security, scroll to Security and click Open Anyway. Confirm, and from then on it opens with a double-click.

    On macOS 13 or 14 you can instead Control-click the app and choose Open.

Requirements

  • Mac with Apple silicon, M1 or later. Intel Macs are not supported.
  • macOS {{min_macos_name}} or later
  • About {{disk_mb}} MB of free space
  • Plays at 60 fps on a MacBook Air M3 on the default Balanced preset
Check the download (SHA-256) {{sha256}}

In Terminal: shasum -a 256 ~/Downloads/{{dmg_name}}

On Windows

  1. Unzip the download

    Right-click {{win_name}} in your Downloads folder and choose Extract All. You get a MazeCitadel folder with the game inside. Keep it wherever you like; there's nothing else to install.

  2. Double-click MazeCitadel.exe

    It's the only file in the folder. The game data is built into it.

  3. Allow it once past SmartScreen

    Maze Citadel isn't code-signed yet, so the first run shows "Windows protected your PC". Click More info, then Run anyway. From then on it opens with a double-click.

Requirements

  • Windows 10 or 11, 64-bit
  • A graphics card with Vulkan or Direct3D 12, roughly 2016 or newer
  • Saves and settings live in %APPDATA%\Maze Citadel
  • The Windows build is new and less tested than the Mac one. Its frame rate hasn't been measured yet.
Check the download (SHA-256) {{win_sha256}}

In PowerShell: Get-FileHash ~\Downloads\{{win_name}}

Or in Command Prompt: certutil -hashfile %USERPROFILE%\Downloads\{{win_name}} SHA256

On Linux

  1. Extract the archive

    Extract {{linux_name}} with your file manager, or in a terminal: tar -xzf {{linux_name}}. You get a MazeCitadel folder with the game inside.

  2. Run MazeCitadel.x86_64

    Double-click it in your file manager, or from a terminal in that folder: ./MazeCitadel.x86_64. The game data is built into it, so there's nothing else to install.

  3. Keep the graphics drivers current

    The game draws with Vulkan. If it doesn't start, update your distribution's graphics drivers first.

Requirements

  • A 64-bit x86 Linux with up-to-date graphics drivers
  • A graphics card with Vulkan, roughly 2016 or newer
  • Saves and settings live in ~/.local/share/Maze Citadel
  • The Linux build is new and less tested than the Mac one. Its frame rate hasn't been measured yet.
Check the download (SHA-256) {{linux_sha256}}

In a terminal: sha256sum ~/Downloads/{{linux_name}}
